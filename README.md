# Bloomix Admin API

Bloomix 어드민(운영 콘솔) 백엔드

Bloomix는 공공 API로 수집한 실제 공연·전시 정보를 기반으로, 자체 모의 예약·대기·결제·동행 모집·현장 참여를 제공하는 문화생활 플랫폼이다.
어드민은 이 데이터와 예약을 운영한다.

## 기능 범위

### 데이터 수집 관리
- 공공 API 수집 실행 이력 조회 (출처, 시각, 신규/변경/실패 건수)
- 실패 건 조회 및 재처리
- 여러 출처의 같은 행사 병합 결과 확인 / 분리

### 행사 관리
- 행사 목록/상세 조회, 노출 여부 관리
- 출처별 원본 데이터 비교

### 회차 · 정원 관리
- 행사별 회차 등록/수정
- 회차 전체 정원 및 판매처별 할당량 설정
- 예매 오픈 시각 설정

### 예약 · 대기 관리
- 회차별 예약자/대기자 현황 조회
- 예약 상세 조회

### 회원 관리
- 회원 목록/상세 조회 (개인정보 마스킹)

### 시스템 관리
- 어드민 메뉴 관리 (사이드바)
- 공통코드 그룹/코드 등록/수정/조회
