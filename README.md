# Bloomix Admin API

Bloomix 어드민 백엔드

## 기능 범위

### 사용자 관리
- 사용자 목록/상세 조회
- 사용자 제재

### 식물 카드 관리
- 식물 카드 등록/수정/삭제
- 식물 이미지 업로드

### 테마 관리
- 테마 등록/수정

### 포인트 관리
- 사용자별 포인트 내역 조회
- 포인트 수동 지급/차감 (거래 이력 기록)

### 부케 조회
- 생성된 부케 목록/통계 조회 (읽기 전용)

### Rate Limit 정책 관리
- Rate Limit 정책 등록/수정/조회

### 이미지 생성 Job 모니터링
- 실패한 Job 조회
- Job 수동 재처리

### 공통코드 관리
- 공통코드 그룹/코드 등록/수정/조회
